# Assets

Esta pasta concentra os assets visuais próprios do G2d.

Todos os assets finais de produção devem ser preferencialmente PNG e seguir `docs/ART-BIBLE.md`.

Estrutura inicial planejada:

```text
assets/
  world/
  cities/
  buildings/
  units/
  factions/
  portraits/
  ui/
  maps/
```

Não adicionar artes copiadas de jogos existentes.
